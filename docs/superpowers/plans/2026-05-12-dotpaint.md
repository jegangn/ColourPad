# DotPaint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an installable, fully offline PWA with two kids' games — drag-a-line connect-the-dots and finger-paint colouring — backed by 200 AI-generated pictures, runnable from a Samsung Tab S8 home-screen icon.

**Architecture:** Static, vanilla-JS PWA — no framework, no build step, no bundler. Bun serves files in dev. Service worker pre-caches everything for offline use. localStorage holds settings + gallery snapshots. Web Audio + SpeechSynthesis for sound. Single-source-of-truth design tokens in CSS custom properties feed claymorphic components.

**Tech Stack:** HTML5, Vanilla JS (ES modules), CSS custom properties, Web Audio API, SpeechSynthesis API, Canvas 2D. Bun (dev server + test runner). Anthropic SDK (one-shot picture generation script).

**Spec:** [docs/superpowers/specs/2026-05-12-colouring-and-dot-game-design.md](../specs/2026-05-12-colouring-and-dot-game-design.md)

## Security model

The app is single-user, offline, no network IO at runtime, no server, no shared state. The only "untrusted" string is the **user-photo name** typed by the parent. Two safeguards apply throughout the codebase:

1. A small `escapeHtml(s)` helper in `src/js/lib/util.js` (introduced in Task 4) is applied wherever any string from `manifest.json`, `storage.getUserPhotos()`, or `storage.getGallery()` interpolates into a template literal that becomes `.innerHTML`.
2. Static template strings (no interpolation) use `.innerHTML`. Any place that interpolates a value not statically known at write-time goes through `escapeHtml()` or `.textContent`.

Subagents implementing screen tasks must follow this rule. Code review (Task 21) explicitly verifies it.

## Parallelism

Tasks marked **[parallel-safe]** can be dispatched concurrently to subagents because they touch disjoint files. Tasks marked **[sequential]** must complete before downstream waves start. Recommended dispatch waves are listed in the dependency graph at the bottom.
