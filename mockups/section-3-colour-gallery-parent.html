Notes

Colouring

  • Brush: finger drag paints freely; stroke uses the selected colour and brush size. Strokes go into a canvas overlay above the SVG outline — outline is always visible on top.
  • Palette: 8 default colours (red, yellow, green, blue, purple, orange, black, white/eraser). 3 brush sizes. White acts as an eraser.
  • Top buttons: Undo (last stroke), Clear (whole canvas after a confirm), Save (⭐ takes a snapshot to gallery).
  • Sound: soft brush whoosh while dragging.

Gallery

  • Grid of saved snapshots. Tap to view full-size, long-press for delete confirm.
  • Stored as base64 PNGs in localStorage. ~50KB each, comfortably 100+ before space matters.
  • Empty state shows clear instructions for how to save.

Parent area

  • PIN gate: 4-digit PIN keeps a 5yo out of settings. Default 1234, changeable inside.
  • Add photo: Pick from gallery → preview shows original + auto-generated outline (browser edge detection) → confirm to add to the colouring picker (flagged with a 📷 badge so you can find your own).
  • Settings: Toggles for faint-outline hint, sound, voice. Change PIN. Manage gallery. Stats (just a count, nothing tracking-y).
